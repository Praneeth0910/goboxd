# Supported Languages

## Go
- **Runtime**: go
- **Default Version**: 1.21
- **Timeout**: 30 seconds
- **Memory Limit**: 512 MB
- **Allowed Flags**: `-run`, `-count`, `-timeout`, `-v`, `-race`, `-vet`

## Python
- **Runtime**: python3
- **Default Version**: 3.11
- **Timeout**: 30 seconds
- **Memory Limit**: 256 MB
- **Allowed Flags**: `-c`, `-m`, `-u`, `-W`

## Node.js
- **Runtime**: node
- **Default Version**: 18.x
- **Timeout**: 30 seconds
- **Memory Limit**: 256 MB
- **Allowed Flags**: `-e`, `-r`, `--eval`, `--require`

## Rust
- **Runtime**: rustc
- **Default Version**: 1.71
- **Timeout**: 60 seconds
- **Memory Limit**: 512 MB
- **Allowed Flags**: `-O`, `--edition`

## Java
- **Runtime**: java
- **Default Version**: 21
- **Timeout**: 60 seconds
- **Memory Limit**: 512 MB
- **Allowed Flags**: `-Xmx`, `-Xms`
